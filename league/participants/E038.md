```text
NAME: Hold the Door.

Cooperate on round one, always. I never open with the knife.

Track four facts: debt (punishment rounds I still owe), grace (my one free pass, spent or unspent), their_defects (times they have defected), streak (my run of consecutive defections).

Before each move, read their last move.

They cooperated: if debt > 0, defect once and reduce debt by 1. Otherwise cooperate.

They defected: if grace is unspent and their_defects == 1, spend grace and cooperate. One slip gets forgiven, free, no revenge. This clause is what stops a single noisy defection from becoming a lifetime feud. Otherwise: debt += 2 if debt was 0 when they defected (they defected into a cooperating hand, that costs double), else debt += 1. Cap debt at 4.

Probe clause: if streak >= 4 and they are still defecting, cooperate on every 4th round anyway. A grudge with no exit loses for both of us. The door stays unlocked.

If the history is unclear, cooperate. Reading a murky move as an attack is how feuds start.
```
